Read the relation and its rendering boundaries

EI specification and implementation boundary. Joe’s EI specification assigns AI only source-occurrence transcription. This page is an illustrative implementation of the stated geometric relations; it does not establish a complete EI implementation. “Binary” here means a relation between addressed things. It does not replace those things with 0s and 1s.

Current geometry boundary. Joe’s latest explanation is face-to-face cube stacks. This version retains its earlier near-even direction model as a numerical approximation while the branch-frame/contact relation is clarified. The tetrahedral N=4 arrangement is not face contact on one rigid parent cube. Shared addressed shell patterns are implemented here; literal cube-face contact is not established. Centre spacing remains tied to the retained dimensions by (parent size + child size)/2; absolute lengths are unspecified, with no independent free-distance control.

Earlier segmented-sphere approximation. The relation has N sphere segments and N children: one whole sphere, two hemispheres, and boundaries meeting at top and bottom. This page now repeats any selected count from 1 to 118. Child centres lie at equal radius from their parent. General-N directions use a deterministic Fibonacci spherical distribution as the explicit numerical approximation for the stated even-spreading requirement, not an exact derivation of segment boundaries. The optional sphere and radial lines are guides; full segment boundary surfaces are not implemented.

Direction conventions. One child uses local +Y; two use ±Y. Three use exact 120° spacing on a polar great circle: C1 is +Y, C2/C3 have Y=−1/2 and X=±√3/2, with Z=0. This plane and indexed orientation are explicit display conventions, not a physical or unique derivation. Four retain tetrahedral directions; six retain ±X, ±Y, ±Z. Other counts use the spherical approximation. These choices do not assert that every pair of children is equally spaced. For six, adjacent distances are √2 times the radius and opposites are twice it.

Resolve an addressed lineage. Resolve selected centre admits that actual parent and its N immediate children, with the configured inherited size and complete current transforms. Ancestors remain dependencies and the unexpanded recursive rule is retained. Breadcrumbs resolve an ancestor grain; select a child and resolve again to proceed. Resolving does not change camera framing, angles, time, values or drafts. Focus this grain explicitly changes the camera. Additional descendant shell paths are opt-in within this view. This is the actual repeated relation at the selected grain, not a simultaneous miniature entire hierarchy inside each dot. The observer’s parent frame remains the global root. Ordinary advanced centre-domain/range controls remain available and exit this one-generation grain view.

Calculated paths and observations. Dashed calculated curves are evaluated from the same admitted parent-child relations before motion occurs. They never enter the observed sample history or FIR observation receipts. Parent-relative calculations cover one complete local-phase cycle when local turn is nonzero. World curves use a verified common phase period only when it is at most 60 seconds; otherwise they show an open 30-second forecast. Zero rates can legitimately produce stationary paths. The phase origin and sample count are shown. Curves are finite piecewise-linear approximations; distinct coincident addresses remain distinct. Geometry, rates, filter or explicit phase reset rebuild the relevant cache; camera inspection only reprojects it. An expired open forecast advances to a new declared phase origin. The display makes no prediction of physical behaviour.

Observer and path frames. The default observer turns with the root parent. At zero relative view turn, the parent has zero relative turn while its absolute model rotation continues. World view uses an external frame. Parent-relative paths remove the root rotation recorded at each sample’s own time; world paths use the original world positions. Switching view does not change the model or rewrite history. Samples without a recorded root phase remain world-only. Background reference points stay fixed in world coordinates and move on screen only through the camera. The observer and reference points are excluded from all centre counts.

Centres first. Trails connect actual sampled world positions from the running transform, in time order. They are not parent–child connectors or invented curves. Root remains at its fixed centre. Changing count, depth or display scale starts a new path segment and retains earlier geometry separately within a finite history budget. No path joins across the geometry change. Time, rotation phase, camera view, filled values and address-keyed drafts survive these changes. Newly exposed centres may lie outside the view; use Fit to reframe. Reset motion clears history. Rate changes preserve history. Camera moves only change the view.

Inherited colour. Each child adds its ordered segment/child-index colour contribution to the contributions retained from all its ancestors. The same child-index colour order repeats at every generation; the visible colour is their equal-weight RGB average. The broad RGB hue palette identifies segment origin and ancestry; it has no wavelength calibration. Palette and blending are display conventions.

The whole pattern inside its primary centre. A second instance repeats all current centre paths at a smaller scale inside root. Select “Finer pattern inside root”, then “Focus centre” to inspect it. Both instances share the same relation and motion parameters; addresses retain their instance prefix. One inner instance is rendered, not an infinite limit. Its scale fits the finite pattern inside root and is an explicit display convention.

Anchored inspection. Wheel zoom holds the world point under the cursor. When the spherical guide is visible, the nearest ray-intersected spherical guide supplies that point. Otherwise a nearby centre’s depth, or the selected centre’s viewing plane, supplies its depth. Pinch holds that point under the moving midpoint. Ongoing model motion remains independent.
